# Blog Django

> Blog construido com Django (Python) e containerizado com Docker Compose. Inclui sistema de posts e painel administrativo nativo do Django.

## Stack

- Python
- Docker

## Prerequisitos

- Docker e Docker Compose

## Como executar

```bash
# Clone o repositorio
git clone https://github.com/meirelesdev/blog-django.git
cd blog-django

# Inicie a aplicacao
docker-compose up -d
```
